# Food-Truck-Site

This is a responsive website for a food truck business called "Sip Happens". The site is designed to adapt to different screen sizes using Bootstrap and custom CSS styling.

## Breakpoint and Changes

### Small Screens (Default, <768px)
-**Hero Title: Font size is set to `2.5rem`.
-**Lead Text: Font size is set to `1.25rem`.
-**Cards: Stack vertically in  a single column (`col-12`).

### Medium Screens (>768px)
-**Hero Title: Font size increases to `4.5rem` for better emphasis.
-**Lead Text: Font size increases to `1.75rem` for improved readability.
-**Cards: Display in two columns (`col-md-6`).

### Large Screens (>992px)
-Cards: Display in three columns (`col-lg-4`).
-Paddings and Margins: Increased spacing for a more spacious layout.

## Features
- The layout adjusts across different screen sizes.
- Utilizes Bootstrap's grid system and utility classes for responsiveness.
- Additional CSS typography and layout enhancements.

## How to View
- Open the project in your browser using Live Server.
- Resize the browser window to see how the layout changes at different breakpoints.
